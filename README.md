# Jimbofy
![Screenshot of 'Joker' renamed to 'The One And Only Jimbo'](https://github.com/user-attachments/assets/b52565c1-7a4b-4d17-826f-eca5031f6177)
A remarkably niche mod for Balatro that changes every mention of "Joker" to "Jimbo".

---
## Installation
1. Download [Steamodded](https://github.com/Steamodded/smods) and place it in your 'Mods' directory (or create one at `.../%appdata%/balatro/mods` on Windows, `/Users/$USER/Library/Application Support/Balatro/Mods` on MacOS). You may be prompted to install Lovely, a Balatro mod injector, the latest release of which can be found [here.](https://github.com/ethangreen-dev/lovely-injector/releases/latest)
2. Download the latest release of [Jimbofy](https://github.com/NathanWakinshaw/Jimbofy/releases/tag/v1.0) and extract the .lua file to a directory in your Mods folder.
3. Restart Balatro and check Jimbofy as active in the Mods menu (this should be done by default.)

---
Jimbo is now loose inside your computer. Enjoy!
